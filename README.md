Gradient Generator

A simple web tool that generates random gradients using two colors. Supports both linear and radial gradient types. Perfect for exploring new gradient designs for your web projects!

Features

•	Random Color Generation: Automatically generates two random colors.

•	Gradient Types:Randomly choose between linear and radial gradients.

•	Live Preview: View the generated gradient instantly in the browser.

Installation

1.	Clone or download the repository.

2.	Open the index.html file in your browser to start using the Gradient Generator.
bash

Copy

git clone https://github.com/Aaliyakhan10/Gradient_Generator.git

cd gradient-generator

open index.html

Usage

1.	Open the index.html file in your browser.

2.	Click the "Generate Gradient" button to generate a new random gradient.

3.	Copy the generated CSS code to use it in your web projects.

Example Output

css

Copy

/* Linear Gradient */

background:linear-gradient(270deg, #c5fe4f, #2ea9a3) 

/* Radial Gradient */


background: radial-gradient(circle, #FF5733, #33FF57);
